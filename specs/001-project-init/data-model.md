# Data Model: Browser Extension Project Initialization

**Feature**: 001-project-init  
**Date**: 2025-11-11  
**Status**: Complete

## Overview

This feature is a project initialization/scaffolding task with minimal runtime data requirements. The data model focuses on configuration entities rather than persistent data structures.

## Configuration Entities

### Extension Manifest (manifest.json)

**Purpose**: Defines extension metadata, permissions, and entry points for Chrome browser

**Structure**:
```typescript
interface ManifestV3 {
  manifest_version: 3;
  name: string;              // "GitHub-Switcher"
  version: string;           // Semantic version "0.1.0"
  description: string;       // Extension description
  
  content_scripts: Array<{
    matches: string[];       // ["*://github.com/*", "*://*.github.com/*"]
    js: string[];           // ["content.js"]
  }>;
  
  permissions: string[];     // Empty initially (minimal permissions)
  
  icons?: {
    "16": string;
    "48": string;
    "128": string;
  };
}
```

**Validation Rules**:
- `manifest_version` must be 3 (Manifest V3 requirement)
- `matches` limited to GitHub.com domains only
- `permissions` array should remain empty (minimal privilege principle)
- Version must follow semantic versioning (MAJOR.MINOR.PATCH)

**Lifecycle**: Static file, generated by Plasmo or manually maintained

### TypeScript Configuration (tsconfig.json)

**Purpose**: TypeScript compiler settings for strict type checking

**Structure**:
```typescript
interface TypeScriptConfig {
  compilerOptions: {
    strict: true;                    // Strict mode enabled
    target: "ES2020";               // Modern JS target
    module: "ESNext";               // ES modules
    moduleResolution: "bundler";    // For Plasmo/Vite
    esModuleInterop: true;
    skipLibCheck: true;
    
    baseUrl: ".";
    paths: {
      "@/*": ["src/*"];             // Path alias for clean imports
    };
    
    types: ["chrome", "node"];      // Chrome extension APIs
  };
  
  include: ["src/**/*"];
  exclude: ["node_modules", "dist", "build"];
}
```

**Validation Rules**:
- `strict` must be `true` (constitution requirement)
- `noImplicitAny` implicitly enabled by strict mode
- Path alias `@/*` must map to `src/*`

**Lifecycle**: Static configuration file

---

### Biome Configuration (biome.json)

**Purpose**: Linting rules for code quality enforcement

**Structure**:
```typescript
interface BiomeConfig {
  $schema: string;
  
  linter: {
    enabled: true;
    rules: {
      recommended: true;
      suspicious: {
        noExplicitAny: "error";     // Enforce no 'any' type
        noConsoleLog: "warn";       // Warn on console.log
      };
      complexity: {
        noUselessConstructor: "error";
      };
    };
  };
  
  formatter: {
    enabled: false;                  // Prettier handles formatting
    indentStyle: "space";
    indentWidth: 2;
    lineWidth: 100;
  };
}
```

**Validation Rules**:
- Linter must be enabled
- `noExplicitAny` set to "error" (no `any` types)
- Line width ≤ 100 characters

**Lifecycle**: Static configuration file

### Package Manifest (package.json)

**Purpose**: Node.js project metadata, dependencies, and scripts

**Structure**:
```typescript
interface PackageJson {
  name: string;                    // "github-switcher"
  version: string;                 // "0.1.0"
  description: string;
  type: "module";                  // ES modules
  
  scripts: {
    dev: string;                   // "plasmo dev"
    build: string;                 // "plasmo build"
    test: string;                  // "vitest run"
    "test:watch": string;          // "vitest"
    "test:coverage": string;       // "vitest run --coverage"
    lint: string;                  // "biome check src"
    "lint:fix": string;            // "biome check --apply src"
    format: string;                // "prettier --write src"
    "format:check": string;        // "prettier --check src"
    typecheck: string;             // "tsc --noEmit"
    prepare: string;               // "husky install"
  };
  
  dependencies: Record<string, string>;       // Runtime dependencies
  devDependencies: Record<string, string>;    // Development dependencies
  packageManager: "pnpm@8.x.x";              // Enforce pnpm
}
```

**Validation Rules**:
- `type` must be "module" for ESM support
- `packageManager` field enforces pnpm
- All scripts must be defined for CI/CD

**Lifecycle**: Managed by pnpm, lockfile (pnpm-lock.yaml) ensures reproducible builds

interface BuildConfig {

## Runtime State (In-Memory Only)

### GitHub Page Detection State

**Purpose**: Track whether current page is a GitHub page

**Structure**:
```typescript
interface GitHubPageState {
  isGitHubPage: boolean;          // URL matches GitHub domain
  pageType: 'repo' | 'file' | 'other' | null;  // Future: page classification
}
```

**Validation Rules**:
- Detection logic in `src/lib/detectGithub.ts`
- No persistence (pure function based on `window.location`)

**Lifecycle**: Computed on page load, no storage

---

## No Persistent Storage

Per requirements:
- **No IndexedDB**: No client-side database
- **No localStorage**: No persistent key-value storage
- **No cookies**: No cookie read/write
- **No chrome.storage**: No extension storage APIs

All state is ephemeral and computed from current page context.

## Relationships

```
manifest.json
  └── content_scripts → src/contents/index.ts

src/contents/index.ts
  ├── imports → src/lib/detectGithub.ts
  ├── imports → src/lib/config.ts (feature flags)
  └── imports → src/utils/logger.ts

package.json
  ├── defines → pnpm scripts
  ├── declares → dependencies
  └── enforces → pnpm package manager

tsconfig.json
  └── configures → TypeScript compiler for src/**/*

biome.json
  └── configures → Linter for src/**/*
```
