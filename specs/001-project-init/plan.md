## Summary

Initialize a frontend-only browser extension skeleton using TypeScript, Plasmo framework, pnpm, with Biome for linting and Prettier for formatting. The extension will detect GitHub pages via content scripts without modifying the DOM by default. Deliverables include an installable MV3 extension with source code and comprehensive README covering manual installation and development mode setup.

## Technical Context

**Language/Version**: TypeScript 5.x with strict type checking enabled  
**Primary Dependencies**: Plasmo (browser extension framework), Biome (linter), Prettier (formatter)  
**Build Tool**: Plasmo build system with pnpm as package manager  
**Storage**: N/A (no persistent storage in initial iteration)  
**Testing**: Vitest for unit tests, manual smoke testing for extension loading  
**Target Platform**: Chrome browser (Manifest V3), development mode  
**Project Type**: Single project (browser extension)  
**Performance Goals**: Build time <30s, lint time <10s, setup time <5min  
**Constraints**: 
- Minimal permissions (only GitHub.com domain access)
- No eval or remote script injection
- Zero user data persistence
- No cookie access
- Content scripts only (no popup/options pages)
**Scale/Scope**: Single developer, initial iteration, independent codebase with zero coupling to existing modules
